# 🐝 Smart Honey Purity Analysis System

An AI and IoT-based smart system designed to distinguish between Sidr and Talh honey and detect adulteration with high precision.
## 📌 About the Project
A smart portable device leveraging **Raspberry Pi 4** and advanced sensors to read chemical and physical indicators (pH, TDS, and Temperature), processing data in real-time through machine learning models to deliver instant, reliable purity reports.

## 🛠️ Hardware & Components
* **Core Controller:** Raspberry Pi 4 Model B.
* **Sensors:** pH Sensor Kit, TDS Sensor Module, DS18B20 Waterproof Temperature Sensor.
* **Signal Converters:** MCP3008 (ADC) & CJMCU-ADS1115 (16-Bit).
